# Instagram Auto-Publishing Setup Guide

This guide walks you through creating an Instagram Business account and getting the access tokens needed for the marketing dashboard to auto-publish content.

## Overview

The dashboard uses the **Instagram Graph API** (v21.0) to publish posts, carousels, and reels directly to your Instagram Business account. You need two things:

1. An **Instagram Business Account** linked to a Facebook Page
2. A **long-lived access token** with publishing permissions

## Step 1: Create a Facebook Page

If you already have a Facebook Page for the game, skip to Step 2.

1. Go to [facebook.com/pages/create](https://www.facebook.com/pages/create)
2. Choose category: **App Page** or **Gaming**
3. Name it "The Resistance Night" (or your preferred brand name)
4. Add a profile picture and cover photo
5. Click **Create Page**

## Step 2: Set Up Instagram Business Account

1. Download the Instagram app on your phone
2. Create a new account (or use an existing one)
3. Go to **Settings > Account > Switch to Professional Account**
4. Choose **Business** (not Creator)
5. Select a category (e.g., "App" or "Gaming")
6. **Link your Facebook Page** when prompted (this is required for the API)

## Step 3: Create a Meta Developer App

1. Go to [developers.facebook.com](https://developers.facebook.com)
2. Click **My Apps > Create App**
3. Choose **Business** as the app type
4. Name your app (e.g., "Resistance Night Marketing")
5. Click **Create App**

### Add Instagram Graph API

1. In your app dashboard, click **Add Product**
2. Find **Instagram Graph API** and click **Set Up**
3. This adds the Instagram API to your app

## Step 4: Generate Access Tokens

### Short-Lived Token (for testing)

1. Go to [Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. Select your app from the dropdown
3. Click **Generate Access Token**
4. Grant these permissions when prompted:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
5. Copy the token (this expires in about 1 hour)

### Long-Lived Token (for production)

Short-lived tokens expire quickly. Exchange yours for a long-lived one:

```bash
curl -s "https://graph.facebook.com/v21.0/oauth/access_token?\
grant_type=fb_exchange_token&\
client_id=YOUR_APP_ID&\
client_secret=YOUR_APP_SECRET&\
fb_exchange_token=YOUR_SHORT_LIVED_TOKEN"
```

Replace:
- `YOUR_APP_ID`: From your Meta app dashboard (Settings > Basic)
- `YOUR_APP_SECRET`: From your Meta app dashboard (Settings > Basic)
- `YOUR_SHORT_LIVED_TOKEN`: The token from the Graph API Explorer

The response will contain a `access_token` field. This long-lived token lasts about 60 days.

**Save this token.** You will paste it into Vercel as `INSTAGRAM_ACCESS_TOKEN`.

### Refreshing the Token

Long-lived tokens expire after ~60 days. Refresh before expiry:

```bash
curl -s "https://graph.facebook.com/v21.0/oauth/access_token?\
grant_type=fb_exchange_token&\
client_id=YOUR_APP_ID&\
client_secret=YOUR_APP_SECRET&\
fb_exchange_token=YOUR_CURRENT_LONG_LIVED_TOKEN"
```

Set a calendar reminder to refresh every 50 days.

## Step 5: Get Your Instagram Business Account ID

Using your long-lived token:

```bash
curl -s "https://graph.facebook.com/v21.0/me/accounts?access_token=YOUR_TOKEN"
```

This returns your Facebook Pages. Find the page linked to Instagram and copy its `id`.

Then get the Instagram Business Account ID:

```bash
curl -s "https://graph.facebook.com/v21.0/YOUR_PAGE_ID?fields=instagram_business_account&access_token=YOUR_TOKEN"
```

The response will have:

```json
{
  "instagram_business_account": {
    "id": "17841400000000000"
  }
}
```

Copy the `id` value. This is your `INSTAGRAM_BUSINESS_ACCOUNT_ID`.

## Step 6: Add to Vercel

In your Vercel project, go to **Settings > Environment Variables** and add:

| Variable | Value |
|----------|-------|
| `INSTAGRAM_ACCESS_TOKEN` | Your long-lived access token |
| `INSTAGRAM_BUSINESS_ACCOUNT_ID` | The numeric ID from Step 5 |

## Step 7: Test Publishing

After deploying with the environment variables set, test by calling:

```bash
curl -X POST https://your-app.vercel.app/api/instagram/publish \
  -H "Content-Type: application/json" \
  -d '{"contentId": "some-content-id"}'
```

Or use the dashboard UI to approve and publish content.

## Content Types Supported

The Instagram integration supports three content types:

| Type | How It Publishes |
|------|-----------------|
| **Post** | Single image with caption and hashtags |
| **Carousel** | Multi-image post (up to 10 slides) |
| **Reel** | Video content with cover image |

All content is generated by the AI agents and stored in the dashboard for review before publishing.

## Important Notes

- **Image URLs must be public.** The Instagram API fetches images from URLs you provide. They must be publicly accessible (no localhost, no authenticated URLs).
- **Rate limits.** Instagram allows 25 API calls per user per hour. The dashboard batches requests to stay within limits.
- **Content review.** The API has automated checks. Posts that violate Instagram's community guidelines will be rejected.
- **Video requirements.** Reels must be MP4, 3 to 90 seconds, at least 540px wide.

## Troubleshooting

**"Invalid OAuth access token":** Your token has expired. Generate a new long-lived token using Step 4.

**"Page not found" or "Object does not exist":** Check that your Facebook Page is correctly linked to your Instagram Business account. Go to your Facebook Page Settings > Instagram to verify.

**"Media creation failed":** The image URL is likely not publicly accessible. Make sure images are hosted on a public URL (Vercel, Cloudinary, or similar).

**"Permission denied":** Your app may not have the required permissions. Go to [Graph API Explorer](https://developers.facebook.com/tools/explorer/) and re-grant `instagram_content_publish`.

## Security Notes

- Never commit your access token to the repository
- Store tokens only in Vercel environment variables
- Use the `.env.local` file for local development (it is gitignored)
- Rotate your token if you suspect it has been compromised
